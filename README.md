## 🕶️ Sobre o projeto

O **VoidPanel** é um projeto voltado para disciplina, foco e desenvolvimento pessoal, criado para ajudar pessoas a organizarem sua rotina, acompanharem seus objetivos e construírem hábitos melhores.

Acreditamos que a evolução não depende apenas de motivação, mas de consistência, responsabilidade e disciplina diária.

> "A disciplina começa quando a motivação acaba."

## ⚡ Objetivos

- 🎯 Desenvolver disciplina e consistência.
- 📈 Acompanhar metas e progresso pessoal.
- 🧠 Incentivar o foco e o autocontrole.
- 📅 Organizar hábitos e rotinas.
- 🔥 Transformar pequenas ações em grandes resultados.

## 🛠️ Tecnologias

- **HTML5** — Estrutura do site.
- **CSS3** — Interface e design.
- **PHP** — Lógica e funcionalidades do sistema.

## 🌑 Nossa filosofia

```text
No excuses.
No distractions.
No shortcuts.

Only discipline.
Only progress.
Only evolution.
```

O objetivo não é ser melhor que os outros, mas superar a própria versão de ontem.

## 🚀 Desenvolvimento

Novas funcionalidades serão adicionadas conforme o projeto evoluir.
